# Контент план факт

Локальное веб-приложение для планирования контент-производства SMM-менеджера: контент, публикации по площадкам, учет времени, календарь и план-факт.

## Что реализовано

- Dashboard с KPI, планом/фактом, pipeline, ближайшими событиями и продуктами.
- Быстрое создание Content Item и отметка публикации.
- Kanban с drag-and-drop и режимом списка.
- Страница «Сегодня» для задач и внесения выполненной работы.
- Календарь месяца и недели.
- План-факт с ожидаемым прогрессом месяца и редактированием месячных планов.
- История работ с фильтрами и распределением времени.
- Настройки продуктов и соцсетей: добавление, архивирование и восстановление.
- Несколько публикаций одного материала на разных соцсетях без двойного учета факта.
- Соавторы Reels, плановые даты съемки и публикации.
- XLSX-экспорт отчета на пять листов.
- Демо-данные хранятся локально в браузере через localStorage.

## Стек

Next.js 16, App Router, TypeScript, Tailwind CSS, Lucide, date-fns, Recharts (подготовлен для графиков), Zod, React Hook Form (подготовлен для Supabase-форм), dnd-kit и XLSX.

## Данные и Supabase

Сейчас приложение запускается без аккаунта и базы: данные сохраняются в localStorage текущего браузера. Для облачной версии и общего доступа нужно создать бесплатный проект Supabase, применить `database/001_initial_schema.sql`, затем создать `.env.local` на основе `.env.example`:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

В браузер можно передавать только URL и anon key при включенном Row Level Security. Service role key не добавляйте в клиентский код.

Демо-данные можно удалить кнопкой очистки данных в будущей версии или очистив ключ `content-plan-fact-local-v1` в DevTools → Application → Local Storage.
